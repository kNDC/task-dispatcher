# Task Dispatcher <!-- omit in toc -->

Класс для обработки входящего потока независимых задач с разной очерёдностью/приоритетностью, обрабатываемого многопоточно с использованием встроенных возможностей C++17/20.

## Предоставляемые возможности
* Поддержание многопоточной загрузки задач вида `std::function<void()>`;
* Обработка поступающих задач в соответствии с их приоритетностью: задачи более высокой важности обрабатываются в первую очередь;

## Обзор класса и вспомогательных сущностей
* Пространство имён -- `dispatcher`;
* `TaskPriority` -- `enum class`, перечень очерёдностей/приоритетностей обработки: `High` (высокая), `Normal` (обычная).  Возможно указание иного количества очерёдностей со внесением изменений в переменные: `n_priorities` -- количество очерёдностей, `priorities` -- хранилище очерёдностей и их порядков (`std::map<TaskPriority, size_t>`);
* `UnboundedQueue<T>` -- шаблонный класс неограниченной очереди с многопоточным доступом, поддерживающий методы:
  * `void push(const T&)`, `void push(T&&)` -- внесение элементов в очередь,
  * `std::optional<T> try_pop()` -- извлечение элемента с вершины очереди с блокировкой при её пустоте;
  * `void drain()` -- после применения снимает блокировку в `try_pop` с возвращением `std::nullopt`;

* `BoundedQueue<T>` -- шаблонный класс ограниченной очереди с многопоточным доступом, поддерживающий методы:
  * `void push(const T&)`, `void push(T&&)` -- внесение элементов в очередь с блокировкой по полном израсходовании её ёмкости;
  * `std::optional<T> try_pop()` -- извлечение элемента с вершины очереди с блокировкой при её пустоте;
  * `void drain()` -- после применения снимает блокировку в `try_pop` с возвращением `std::nullopt`;

* `PriorityQueue` -- класс приоритетной очереди, поддерживает методы:
  * `void push(TaskPriority priority, std::function<void()> task)` -- внесение задачи `std::function<void()>` в соответствующую очередь. При использовании `BoundedQueue` поток блокируется при отсутствии доступного запаса ёмкости;
  * `std::optional<T> try_pop()` -- аналогичен `try_pop` в `BoundedQueue` и `UnboundedQueue`;
  * `void drain()` -- аналогичен `drain()` в `BoundedQueue` и `UnboundedQueue`;
  * Конструктор использует `std::map<TaskPriority, std::optional<size_t>>&&` для указания типа очереди каждого уровня приоритетности: значение соответствует `BoundedQueue` соответствующей ёмкости, `std::nullopt` -- случаю неограниченной очереди;

* `TaskDispatcher` - основной класс, обрабатывающий задания, вносимые в `PriorityQueue`, с помощью пула потоков.  Предлагает следующие методы:
  * `const std::unordered_set<std::string_view>& GetAuthors()` -- перечень писателей, чьи работы были внесены в класс;
  * Конструктор использует количество потоков (по умолчанию аппаратно поддерживаемое количество потоков с за вычетом основного потока `std::hardware_concurrency - 1`, но не менее `1`) и `std::map<TaskPriority, std::optional<size_t>>&&` для настройки приоритетной очереди (см. выше);
